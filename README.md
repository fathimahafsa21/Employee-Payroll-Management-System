# Employee Payroll Management System

## About the Project

The **Employee Payroll Management System** is a console-based Java application developed to manage employee information and payroll operations. The system allows an administrator to maintain employee records and automatically calculate employee salary details.

This application was developed as a **group project** for our software development activity.

## Features

* Administrator login
* Add new employees
* View all employee details
* Search for an employee
* Update employee information
* Delete employee records
* Calculate employee salary
* Calculate bonus and tax
* Generate employee salary slips
* Generate payroll summary reports
* Save and load employee records using file handling

## Salary Calculation

The system calculates employee salary using the following:

* **Bonus:** 10% of Basic Salary
* **Tax:** 8% of Basic Salary
* **Net Salary:** Basic Salary + Bonus - Tax

## How to Run the Project

1. Download or clone this GitHub repository.
2. Open the project using a Java IDE or code editor.
3. Open `PayrollSystem.java` from the `src` folder.
4. Compile and run the Java program.
5. Enter the administrator username and password.
6. Select the required option from the main menu.
